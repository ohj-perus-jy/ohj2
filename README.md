# Ohjelmointi 2 (Jyväskylän yliopisto)

[![CC BY-SA 4.0][cc-by-sa-shield]][cc-by-sa]

Tämä on Jyväskylän yliopiston Ohjelmointi 2 -kurssin oppimateriaali.
Materiaali on luettavissa osoitteessa <https://ohjelmointi2.it.jyu.fi>.

Tehtävien palauttaminen vaatii opintojaksolle
[ilmoittautumisen](https://opinto-opas.jyu.fi/2025/fi/opintojakso/tiep111/).

## Löysitkö virheen?

Jokaisen sivun alareunassa on kaksi linkkiä:

- **Ilmoita ongelma** avaa GitHubissa ilmoituslomakkeen, jossa sivun nimi on
  jo valmiina. Kerro, mikä on vialla.
- **Muokkaa** avaa sivun lähdetiedoston GitHubissa. Voit korjata virheen
  suoraan selaimessa ja lähettää korjauksen pull requestina.

Molempiin tarvitaan GitHub-tunnus. Pienetkin huomiot ovat tervetulleita.

Isommat muutokset ja materiaalin ajaminen omalla koneella:
[CONTRIBUTING.md](CONTRIBUTING.md).

Sivusto on tehty [kirjatyökaluilla](https://github.com/ohj-perus-jy/kirjatyokalut),
joita voi käyttää myös omassa kirjassa
([käyttöönotto](https://github.com/ohj-perus-jy/kirjatyokalut#käyttöönotto-uudessa-kirjassa)).
